# Proyecto: Gestión de Población · Way of the Hunter

## Objetivo
Mantener y mejorar el dashboard de gestión de poblaciones cinegéticas de *Way of the Hunter* sin romper las funciones existentes ni perder los datos del usuario.

## Fuente de verdad
- Este repositorio de GitHub contiene la versión versionada del proyecto.
- Archivo principal actual: `Gestión de Población · Way of the Hunter.html`.
- No considerar una modificación como aprobada hasta revisarla y probarla.

## Reglas de trabajo para cualquier IA
1. Antes de cambiar código, leer el archivo actual y describir brevemente qué se va a tocar.
2. Hacer cambios pequeños, concretos y limitados al objetivo solicitado.
3. No rediseñar, renombrar ni reestructurar partes ajenas a la tarea.
4. No eliminar funciones existentes ni cambiar cálculos/reglas de gestión sin autorización expresa.
5. Tener en cuenta que los datos se guardan en el navegador. Proteger la compatibilidad con los datos guardados y las copias de seguridad.
6. Tras cada cambio, indicar qué se modificó, qué pruebas se hicieron y qué queda sin verificar.
7. Si falta información o una regla del juego no está confirmada, indicarlo; no inventar datos.
8. Preferir soluciones sencillas que funcionen en el archivo HTML actual antes de introducir dependencias, servicios o costes nuevos.

## Flujo recomendado
1. Definir un único cambio por tarea.
2. Identificar funciones y datos afectados.
3. Guardar una versión o commit previo.
4. Aplicar el cambio en una copia o rama cuando sea posible.
5. Probar los flujos afectados y comprobar que los datos previos siguen disponibles.
6. Revisar el diff y solo entonces incorporar el cambio a la versión principal.

## Formato de entrega
- Resumen del cambio.
- Archivos afectados.
- Pruebas realizadas y resultado.
- Riesgos o limitaciones pendientes.
